# Contribuicao

1. Trabalhe em branch de feature a partir de `develop`.
2. Abra Pull Request para `develop` (integracao) ou `main` (deploy apos merge).
3. Aguarde CI verde e pelo menos uma revisao antes do merge.
4. Nunca commite secrets, `.env` ou state Terraform.
